# ITAI2373-NewsBot-Final-Jeremy
This project continues from the NewsBot Midterm Exam. The NewsBot Intelligence System 2.0 covers multi-level categorization with confidence scoring, automatic identification of emerging themes and trends, track emotional tone changes over time, understand connections between people, organizations, and events, language Understanding and generation, intelligent summarization, expand analysis with contextual information, query understanding, automatically identify key findings and patterns, compare coverage across different language sources, translation integration, understanding regional perspectives on global events, and automatically identifying and processing multiple languages.
